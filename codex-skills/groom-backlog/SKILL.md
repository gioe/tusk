# groom-backlog

Read [runtime guidance](references/runtime.md). Inspect `tusk setup`, backlog-scan and
relevant task evidence. Apply requested grooming policy with supported commands; preserve
user priorities and dependencies. Close duplicates only with a clear surviving task,
and avoid treating old age as proof that unfinished work is completed. Report changes
and unresolved judgments. Grooming does not authorize implementing the backlog.
