# investigate

Read [runtime guidance](references/runtime.md). Inspect only the code and task context
needed to assess the question. Explain demonstrated causes, impact and actionable options.
Check backlog coverage before proposing tasks. No action needed is a valid result.
An investigation request does not authorize implementation; create tasks only when requested.
