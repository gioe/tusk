# tusk-insights

Read [runtime guidance](references/runtime.md). Scope the report to the user's question.
Use `tusk task-summary`, objective brief, session stats already recorded, and supported
read-only reports. Use `tusk dashboard --help` for requested dashboards. Explain missing
coverage and estimates. Do not mutate task status to make a report look cleaner.
