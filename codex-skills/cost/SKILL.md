# cost

Read [runtime guidance](references/runtime.md). Use `tusk cost --help` to select the
requested task, objective or project. Report recorded costs and coverage honestly;
unavailable pricing or missing telemetry is not zero spend. Do not silently reprice or
rewrite historical sessions for a read-only report. Explain any requested recalculation
using session-stats/session-recalc and the installed pricing data.
