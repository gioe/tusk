# loop

Read [runtime guidance](references/runtime.md). Respect the requested budget and scope.
Use `tusk loop --help` and ready-task selection; execute each chosen task through its
normal criteria, review and merge gates. Reassess readiness after completion. Stop for
explicit user requests, exhausted budgets, unresolved blockers or an empty eligible queue.
Proposed new work is not automatically authorized for creation or execution.
