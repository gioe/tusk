# objective

Read [runtime guidance](references/runtime.md). Distinguish planning from execution:
planning creates/revises approved task structure, while execution works existing tasks.
Use `objective get` and `objective brief`, inspect dependencies and unresolved context.
Create approved tasks through task-import and link their contribution to the objective.
Run ready tasks through the normal Tusk workflow when execution is requested. Close the
objective only after its intended outcome is met, not merely because a queue is empty.
